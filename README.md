# 🛍️ Modest Bloom - E-Commerce Clothing Store

A modern, elegant clothing store web application built with **React + TypeScript**, designed for showcasing and selling modest fashion items for women.

> 🔗 **Live Demo**: [https://your-live-site-link.com](https://your-live-site-link.com)

---

## ✨ Features

- 🧕 Stylish and modest clothing categories (coats, tunics, scarves, etc.)
- 🔍 Live product search with icon
- 🛒 Add to Cart functionality with total price
- 📦 Product detail page with image slider
- 💳 Checkout page with payment integration (PayPal-ready)
- 🔐 React Context for cart state management
- 🔄 Responsive image slider and weekly trends carousel
- 🌐 Language & currency selector (TR / USD)
- 🎨 Fully responsive, user-friendly design

---

## 🛠️ Tech Stack

- **React + TypeScript**
- **React Router DOM** for routing
- **Context API** for cart state
- **CSS** for styling and transitions
- **GitHub Pages / Netlify** for deployment
